Theory
======

Parameterization
----------------

Each stack candidate is represented by seven rigid-body parameters plus zero or
more torsion parameters:

``[cos_like, sin_like, Tx, Ty, Tz, Cx, Cy, torsion_0, ...]``

``cos_like`` and ``sin_like`` are not constrained to the unit circle. The code
recovers the in-plane rotation angle with ``atan2(sin_like, cos_like)``. This
avoids discontinuities at the angle wraparound boundary.

``Tx``, ``Ty``, and ``Tz`` translate each successive monomer copy. ``Cx`` and
``Cy`` define the in-plane center around which the rotation is applied. The
rotation axis is the Z axis after the monomer has been aligned to the XY plane.

Parameter Bounds
----------------

The optimizer clamps rigid-body parameters to physically reasonable ranges:

.. list-table::
   :header-rows: 1
   :widths: 30 35 35

   * - Parameter
     - Lower bound
     - Upper bound
   * - ``Tx``, ``Ty``
     - ``-8.0``
     - ``8.0``
   * - ``Tz``
     - ``2.5``
     - ``6.0``
   * - ``Cx``, ``Cy``
     - ``-5.0``
     - ``5.0``

Torsion parameters are clipped during optimizer updates to ``[-2*pi, 2*pi]``.
Before applying torsions to coordinates, reduced torsion values are clipped to
``[-pi, pi]``.

Stack Construction
------------------

The first monomer is kept as the base layer. Layer ``k`` is generated by
applying the rigid-body transformation matrix to the base monomer ``k`` times.
This produces a one-dimensional stack with a consistent repeat transform.

Objective Function
------------------

For a stack with ``N`` layers, xTB evaluates the isolated monomer energy
``E_mono`` and the stack energy ``E_stack``. The binding energy per interface is

.. math::

   E_{bind} = \frac{(E_{stack} - N E_{mono}) \times 2625.499638}{N - 1}

where the conversion factor maps Hartree to kJ/mol.

The optimizer minimizes:

.. math::

   f(x) = E_{bind} + 10000 \times P_{total}

where

.. math::

   P_{total} = w_{inter} P_{inter} + w_{intra} P_{intra}

The default weights are ``w_inter = 2.0`` and ``w_intra = 5.0``.

Penalty Terms
-------------

Intermolecular clash penalty is a squared violation sum for atom pairs closer
than ``--clash-cutoff``. For stacks with more than two layers, pair penalties
are weighted by ``1 / layer_separation``.

Intramolecular clash penalty ignores bonded and angle-neighbor pairs, then
penalizes nonbonded atom pairs closer than ``--intramol-cutoff``.

Catastrophic overlap screening rejects geometries before xTB if any interlayer
atom distance is below 1.5 Angstrom or if more than five interlayer atom pairs
are below 2.0 Angstrom. xTB failures also receive a large failure penalty.

Torsion Symmetry Reduction
--------------------------

When ``--enable-symmetric-torsions`` is used, the code computes current
dihedral values for all requested torsions and groups torsions whose angles
match, or whose signs are opposite, within
``--symmetric-torsion-tolerance`` degrees. Each group is optimized as one
reduced variable and then expanded to the full torsion vector before geometry
evaluation.
